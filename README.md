One short funny line: the excuse a robot vacuum gives after eating a sock. The vacuum doesn't apologise — it mounts a deadpan legal defence, arguing that anything left on the floor is, by house law, dust. The program writes that single line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
